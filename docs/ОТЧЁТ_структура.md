# Структура отчёта — П-6-23 УП.04.01 Музыкальный магазин

Заполнить в Word/PDF по шаблону задания. Ниже — содержание разделов.

## 1. Титульный лист
Группа, ФИО, УП.04.01, тема «Музыкальный магазин».

## 2. Тема и предметная область
Интернет/розничный музыкальный магазин: каталог инструментов, заказы, лояльность, акции, склад.

Пользователи:
- покупатель — заказ и отзывы;
- продавец — каталог и обработка заказов;
- администратор — пользователи, отчёты, акции, поставщики.

## 3. Схема БД
См. `pocketbase/схема.md`. Связи:
- 1:1 customer ↔ loyalty_card
- 1:N brand/supplier → products, customer → orders
- M:N products ↔ categories, orders ↔ products (order_items)

## 4. Словарь данных
Таблицы полей из `pocketbase/схема.md`.

## 5. Экспорт схемы
`pocketbase/pb_schema.json` (экспорт из админки Settings → Export collections).

## 6. Контракт API
База: `http://127.0.0.1:8090`
- Auth: `POST /api/collections/users/auth-with-password`
- CRUD: `GET/POST/PATCH/DELETE /api/collections/{name}/records`
- Параметры списка: `page`, `perPage`, `sort`, `filter`, `expand`
- Коды: 400/422 валидация, 401/403 доступ, 404, 409 конфликт остатков (клиент)

## 7. Архитектура клиента
Слои: models → repositories → state → screens/widgets.
Маршруты: см. `lib/core/router.dart`.
Права: `lib/models/role.dart` → Permissions.

## 8. Особенность предметной области
`OrderPricingService`: подытог − скидка лояльности − акции; проверка stock → 409.

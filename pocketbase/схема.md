# Схема базы данных — Музыкальный магазин

Коллекции создавать в админке PocketBase в указанном порядке.
Поля `id`, `created`, `updated` добавляет платформа сама.

## Порядок создания

1. `brands`
2. `categories`
3. `suppliers`
4. `products` (связи на brands, suppliers, categories)
5. `customers`
6. `loyalty_cards` (связь 1:1 на customers)
7. `promotions` (связи на brands, categories)
8. `orders` (связь на customers)
9. `order_items` (связи на orders, products)
10. `reviews` (связи на products, customers)
11. Дополнить `users` полями `role`, `customer`

## API Rules (после заполнения seed)

Синтаксис PocketBase. Закрытый замок = только суперпользователь.

### brands, categories

| Правило | Значение |
| --- | --- |
| List / View | пусто (все) |
| Create / Update | `@request.auth.role = "seller" \|\| @request.auth.role = "admin"` |
| Delete | `@request.auth.role = "admin"` |

### suppliers, promotions

| Правило | Значение |
| --- | --- |
| List / View | `@request.auth.role = "seller" \|\| @request.auth.role = "admin"` |
| Create / Update / Delete | `@request.auth.role = "admin"` |

### products

| Правило | Значение |
| --- | --- |
| List / View | пусто |
| Create / Update | `@request.auth.role = "seller" \|\| @request.auth.role = "admin"` |
| Delete | `@request.auth.role = "admin"` |

### customers, loyalty_cards

| Правило | Значение |
| --- | --- |
| List / View | `@request.auth.id != ""` |
| Create / Update | `@request.auth.role = "seller" \|\| @request.auth.role = "admin" \|\| (@request.auth.role = "customer" && id = @request.auth.customer)` |
| Delete | `@request.auth.role = "admin"` |

### orders

| Правило | Значение |
| --- | --- |
| List / View | `@request.auth.role = "seller" \|\| @request.auth.role = "admin" \|\| (@request.auth.role = "customer" && customer = @request.auth.customer)` |
| Create | `@request.auth.id != ""` |
| Update | `@request.auth.role = "seller" \|\| @request.auth.role = "admin"` |
| Delete | `@request.auth.role = "admin"` |

### order_items, reviews

| Правило | Значение |
| --- | --- |
| List / View | `@request.auth.id != ""` |
| Create | `@request.auth.id != ""` |
| Update / Delete | `@request.auth.role = "seller" \|\| @request.auth.role = "admin"` |

## Типы связей (для отчёта)

| Связь | Тип | Как в UI |
| --- | --- | --- |
| product → brand | M:1 | Dropdown |
| product → supplier | M:1 | Dropdown |
| product ↔ categories | M:N | FilterChip |
| customer ↔ loyalty_card | 1:1 | вложенные поля в форме покупателя |
| order → customer | M:1 | Dropdown |
| order ↔ product через order_items | M:N с атрибутами | позиции заказа |
| review → product, customer | M:1 | Dropdown |
| promotion → brand / categories | M:1 / M:N | Dropdown + chips |
